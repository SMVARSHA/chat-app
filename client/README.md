# QuickChat – Real-Time Chat Application

QuickChat is a real-time chat application that allows users to communicate instantly with secure authentication. 
It is built using the MERN stack and supports one-to-one messaging with a responsive UI.

## 🚀 Live Demo
🔗 **Client:** https://chat-app-frontend-nmy0.onrender.com/  
🔗 **Server API:** https://chat-app-server-6b6q.onrender.com/

## ✨ Features
- User authentication (Login & Signup)
- Real-time messaging
- One-to-one chat
- Responsive design
- Secure backend APIs

## 🛠 Tech Stack
**Frontend:** React.js, HTML, CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Real-time:** Socket.io  
**Authentication:** JWT
